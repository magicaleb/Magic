Quick Start

Have them think of an everyday object they're holding.

Tap Hangman to start. Begin with the first prompted letter and ask whether it is in their word.

If no, draw a hangman part. If yes, write it below the gallows. The location of each input advances the anagram.

Solve removes the lower writing and exits performance mode. Undo removes the last stroke and reverses the last answer.

Double-tap the top-right corner for Settings. Double-tap the top-left corner for this help screen.
